# RackVault

Android-App zur mobilen IT-Inventar- und Hardware-Ausleihverwaltung (Projekt im Fach AWE DT3x, Berufskolleg Beckum).

## Geplante Features
- Inventar-Übersicht mit Filterung nach Standort und Status (`MainActivity`)
- Geräte anlegen/bearbeiten inkl. MAC-Vendor-Lookup (`AddEditAssetActivity`)
- Detailansicht mit Ausleihe/Rückgabe & Verlauf (`AssetDetailActivity`)
- Einstellungen & lokaler CSV-Inventur-Export (`SettingsActivity`)
- Lokale Datenhaltung mit `SharedPreferences`, CSV-Export und `SQLite`
